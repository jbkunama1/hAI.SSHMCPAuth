Features

Everything the README promises, summarized.

🔒 API-key auth

Every MCP request must carry the Authorization header. The key lives only at runtime — never baked into the public Docker image. Wrong or missing key = 401 Unauthorized.

🏠 SSH alias registry

Pre-load up to 20 servers and address them by alias (ssh1, ssh2, …) instead of retyping host, user and credentials. The ssh_list_aliases MCP tool never leaks passwords.

🛠️ Admin UI & CLI

A password-protected server on port 8825 manages aliases at runtime — no file editing. Browser login via HttpOnly cookie, CLI via X-Admin-Token.

🚧 Ready for keys & secrets

Credentials are plaintext today, but the alias format already supports key_path. Later you can move them to Docker secrets without changing anything else.

🚀 Docker + Portainer

Published at ghcr.io/jbkunama1/hai.sshmcpauth:latest, deployable from the repo or the web editor, wired to the external highfishNetwork.

📈 MCP over streamable HTTP

Point anything from AnythingMCP to the auth layer’s /mcp route over HTTPS. LAN test endpoint: http://192.168.178.10:8822/mcp.

Deploy

In Portainer: Stacks → Add stack → Repository, URL, Compose path docker-compose.yml, branch main.

# docker network create highfishNetwork
services:
  sshmcp-core:
    image: mingyang91/ssh-mcp:latest
    container_name: sshmcp-core
    restart: unless-stopped
    networks: [highfishNetwork]
    expose: ["8000"]
    volumes:
      - /home/sshmcp:/data
    environment:
      RUST_LOG: "info"
      MCP_PORT: "8000"

  sshmcp-auth:
    image: ghcr.io/jbkunama1/hai.sshmcpauth:latest
    container_name: sshmcp-auth
    restart: unless-stopped
    networks: [highfishNetwork]
    ports:
      - "8822:8822"   # MCP (external:internal)
      - "8825:8825"   # admin UI / CLI
    volumes:
      - ./data:/data:ro
    environment:
      SSHMCP_API_KEY: "CHANGE_ME_WITH_A_LONG_RANDOM_API_KEY"
      SSHMCP_TARGET_HOST: "sshmcp-core"
      SSHMCP_TARGET_PORT: "8000"
      SSHMCP_LISTEN_PORT: "8822"
      SSHMCP_ALIASES_FILE: "/data/ssh_aliases.json"
      SSHMCP_ADMIN_PORT: "8825"
      SSHMCP_ADMIN_PASSWORD: "CHANGE_ME_ADMIN"

networks:
  highfishNetwork:
    external: true

The full table (English) lives in the README. The essentials:

SSHMCP_TARGET_PORTno8000Upstream internal port.
SSHMCP_LISTEN_PORTno8822Auth layer listen port.

SSHMCP_ADMIN_PORTno8825Admin UI / CLI port.
SSHMCP_ADMIN_PASSWORDno(empty)Admin password. Empty = admin disabled.

Generate a key: openssl rand -hex 32. Keep it in Portainer secrets, never in git.
